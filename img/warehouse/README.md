# 倉庫の表面素材

- `floor-green.webp`：提供された緑の通路の写真（01-6305.jpg、04-6307.jpg、08-6311.jpg）を参考に画像生成した、繰り返し用の塗装床素材。1024×1024px。
- `paint-panel.webp`：提供された天井・壁の写真（02-6306.jpg、04-6307.jpg、08-6311.jpg）を参考に画像生成した、繰り返し用の塗装面素材。1024×1024px。

生成指示は、正面から見た平坦な表面、細かな傷・塗装のむら、物品・文字・強い影・照明・パースを含めないシームレス素材です。生成PNGを縮小してWebP（品質88）へ変換しています。床線・天井の継ぎ目・パレット・蛍光灯・配管は3D形状、黄色い幕の織目と接地影はCanvasで作成しています。

これらは実際の床や壁の各地点に対応する記録写真ではありません。提供写真そのものや写真内の部品ラベルは配布物に含みません。

床反射の実装は、同梱のThree.js r128用Reflectorを使用します。
- ソース：https://github.com/mrdoob/three.js/blob/r128/examples/js/objects/Reflector.js
- 同梱先：`vendor/three-r128-reflector.js`（上流コードは変更なし）
