## ver39 — 登録情報と連動する倉庫ナビ

「マップ」→「3D」で全体を表示。「歩く」で同じ地図を通路の目線から確認できます。

- 建物・棚・パレットと、部品の場所登録を分けて描画します。
- 部品コード付きの立体マーカーは**登録場所**を表し、実際の箱の姿・個数・在庫の保証ではありません。登録のない区画も「空」とは断定しません。
- マップの区画を選択して「3D形状」を押すと、「区画だけ」「棚」「パレット置き場」を選べます。棚の段数・高さは模式表示です。未指定の区画を勝手に棚や荷物で埋めません。
- 3Dで部品を検索し、「場所を移動・解除」から1か所ずつ変更できます。移動先は2Dマップをタップします。別の場所の同じ部品は残ります。
- 「場所」→「空になった現品票を読む」→該当する場所を選んで解除します。通常の検索スキャンでは削除しません。バーコードが箱・場所を一意に識別する前提にはしていません。
- 移動・解除直後は「もどす」が使えます。明示的に解除した場所を旧形式の棚情報から復活させません。
- C7300とC00007300は同じコードとして検索できます。別品番への誤案内を避けるため、3D検索はゼロ埋めを除いた完全一致です。

実物を移動しただけでは画面は更新されません。移動・空になったことの登録が必要です。保存先はこれまで通りそのブラウザのlocalStorageで、複数端末の自動共有はありません。変更前に「部品登録」のバックアップ機能で控えを保存できます。

3Dエンジンは既存のThree.js r128をvendor配下に同梱し、3D表示時の外部CDN依存をなくしています。バーコード・OCRの既存の外部ライブラリ利用は継続しています。

## 確認

```sh
node tests/locations.cjs
```

場所追加、複数場所のうち1か所の移動・解除、保存後の復元、旧形式との併用、似た品番への誤一致を確認します。

ブラウザでは、412×850の画面で全体表示・歩行・移動・解除・取り消し・再読み込みを確認。実機のカメラ読み取りと端末ごとの3D速度は別途確認が必要です。
